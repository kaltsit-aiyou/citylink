# CityLink 城邻云｜产品需求文档

版本：V0.1  
状态：草稿

## 1. 产品定位

CityLink 是连接本地居民、商户和兴趣社群的平台。用户可以发现本地商户、浏览或发布探店笔记，并加入兴趣圈子交流。

## 2. 目标用户

- 消费者：发现商户、阅读和发布笔记、关注用户、参与圈子。
- 商户：展示门店信息，后续管理商品和营销活动。
- 圈主及管理员：管理圈子内容和成员。
- 平台管理员：管理平台内容和商户信息。

## 3. 第一版目标（MVP-A）

让用户完成一条基本使用流程：注册或登录 → 发现商户 → 浏览或发布笔记 → 关注感兴趣的用户 → 加入兴趣圈子。

## 4. 第一版功能范围（待细化）

- 账户：注册、登录、个人资料。
- 商户：门店列表、分类、门店详情。
- 笔记：发布、浏览和基础互动。
- 社交：关注与取消关注。
- 圈子：发现、加入和基础讨论。

## 5. 后续版本

活动、优惠券、订单和个性化推荐留到后续版本规划；第一版先验证基础使用流程。
