# CityLink 城邻云｜产品需求文档

版本：V0.2  
状态：草稿

## 1. 产品目标

CityLink 连接本地居民、商户和兴趣社群。用户可以发现门店、分享探店笔记、关注感兴趣的人，并在圈子中交流。

MVP-A 的目标是跑通一条基础流程：注册登录 → 发现门店 → 阅读或发布笔记 → 关注用户 → 加入圈子并参与讨论。

## 2. 用户角色

消费者是 MVP-A 的主要使用者，可以浏览门店和公开内容，登录后发布笔记、互动及参与圈子。

圈子创建者负责自己创建的圈子的基础管理。商户和平台管理员的完整管理功能留到后续版本。

## 3. MVP-A 功能范围

### 3.1 账户

用户可以使用唯一的用户名和密码注册、登录及退出。登录后可以查看和修改自己的基本资料。未登录用户可以浏览公开内容，但不能发布、互动或加入圈子。

### 3.2 门店发现

用户可以查看已有门店的列表，按分类筛选，并进入门店详情页查看名称、地址、分类和简介。第一版的门店资料由项目预先准备，不提供商户自行入驻或编辑入口。

### 3.3 探店笔记

登录用户可以发布包含标题、正文的笔记，可以选择添加图片和关联门店。用户可以浏览笔记列表与详情。笔记作者可以修改或删除自己的笔记。

登录用户可以对笔记点赞、取消点赞、收藏、取消收藏和发表评论。同一用户对同一笔记不能重复点赞或重复收藏。第一版笔记列表先按发布时间展示，不做个性化排序。

### 3.4 关注

登录用户可以关注或取消关注其他用户，查看自己的关注列表，并按发布时间查看所关注用户发布的笔记。用户不能关注自己。

### 3.5 兴趣圈子

用户可以浏览圈子及其公开内容。登录用户可以创建圈子、加入或退出圈子。圈子成员可以发布讨论内容和评论；圈子创建者可以管理自己圈子的基础信息与成员。

## 4. MVP-A 验收场景

准备若干门店和圈子的示例数据。用户 A 注册并登录后，可以浏览一家咖啡店，发布一篇关联该店的探店笔记。用户 B 可以阅读笔记、点赞、评论和关注 A。两人可以加入同一个兴趣圈子并参与讨论。

上述操作需要能够通过后端接口完整演示；展示界面的形式后续确定。未登录操作、重复点赞、关注自己，以及修改他人笔记等不允许的行为，应得到明确反馈。

## 5. 本版不包含

商户自行入驻、门店管理后台、资质审核、活动、优惠券、团购、订单、支付和个性化推荐不属于 MVP-A。附近门店定位、复杂搜索、高并发和微服务改造也留到后续阶段。

## 6. 待确定事项

笔记图片的存储方式、客户端展示形式、示例门店资料的准备方式，需要在架构和工程设计阶段确定。
