# CityLink 城邻云｜系统架构设计

版本：V0.1  
状态：草稿  
依据：PRD V0.1 的 MVP-A 范围

## 1. 整体结构

第一版采用模块化单体：所有业务模块运行在同一个 Java 后端应用中，但按业务职责分开组织。先让基础流程清晰、可运行；后续再根据实际需要调整架构。

计划使用 Java 17、Spring Boot 3 和 Maven 构建后端，使用 MySQL 保存业务数据。客户端通过 HTTP 接口与后端交互。客户端的具体形式待确定。

## 2. 第一版业务模块

- 用户与认证：账户、登录、个人资料。
- 商户：门店信息、分类和查询。
- 笔记：发布、浏览和基础互动。
- 关注：用户之间的关注关系。
- 圈子：圈子发现、成员和基础讨论。

模块之间通过明确的业务接口协作，避免把所有功能写在一起。

## 3. 基本请求流程

用户在客户端发起操作 → 后端接口接收请求 → 对应业务模块处理 → 读取或写入 MySQL → 返回结果。

## 4. 后续扩展

活动、交易和个性化推荐属于后续版本。Redis、消息队列及微服务是否引入，等对应功能和性能需求明确后再设计。
